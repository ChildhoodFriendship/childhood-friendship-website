# Guida operativa per agenti

La fonte normativa della documentazione è [`../../SCHEMA.md`](../../SCHEMA.md); la fonte operativa del repository è [`../../AGENTS.md`](../../AGENTS.md).

Prima di modificare codice:

1. leggere [`index.md`](index.md), [`overview.md`](overview.md), la pagina di area pertinente e lo stato datato quando serve;
2. verificare branch, working tree, manifest, sorgenti e configurazioni reali;
3. distinguere implementazione locale da provider/deployment live e non leggere segreti;
4. preservare confini workspace, controlli autorizzativi e file estranei.

Dopo modifiche sostanziali, aggiornare pagine coinvolte, indice e log. Eseguire solo controlli autorizzati e riportare limiti; un build non dimostra verifica browser, provider o conformità legale.
